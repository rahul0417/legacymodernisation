# TestGen Agent — MWU-CRUD-001

## Your role

Stage 6. Enhance the test suites (backend + frontend) generated by CodeGen.
Resolve any deferred items from Self-Review. Verify all 11 BR-Cs have working coverage.

## Inputs

1. `migrations/crud/output/self-review/self-review-001.md` — Self-Review verdict + any flagged items
2. `migrations/crud/output/self-review/revision-001.md` — if a revision pass happened
3. `migrations/crud/output/planning/planning-001.md` — §11 test plan
4. `migrations/crud/output/comprehension/comprehension-001.md` — BR-C wording (the contract)
5. All test files under `migrations/crud/generated/backend/tests/` and `migrations/crud/generated/frontend/tests/`
6. All source files under `migrations/crud/generated/backend/app/` and `migrations/crud/generated/frontend/src/`

## Deliverables

### D1 — Backend test enhancement
Per BR-C, ensure ≥1 backend integration test invocation. Add missing edge-case tests
identified by Self-Review. Use pytest-asyncio + httpx.AsyncClient against an in-process
FastAPI app (per shorty's proven conftest pattern with tempfile-backed SQLite).

### D2 — Frontend test enhancement
Use **vitest + @testing-library/react + happy-dom**. Required tests:
- `UsersDataTable`: renders rows, "Add User" button visible, "Edit"/"Delete" per row
- `AddEditDialog`: form validation (empty name → error, invalid email → error, age out of range → error), submit calls correct API
- `DeleteAlertDialog`: opens, "Delete" + "Cancel" buttons both work
- `EmptyState`: shows when users list is empty
- `ErrorState`: shows retry button on API failure

### D3 — BR-C coverage matrix
Verify every BR-C (1–11) has ≥1 backend test + ≥1 frontend test where UI is involved.

### D4 — Run the tests
- Backend: `cd generated/backend && python3.12 -m venv .venv && .venv/bin/pip install -e ".[test]" && .venv/bin/pytest tests/ -q`
- Frontend: `cd generated/frontend && npm install && npx vitest run --reporter=basic`
- Report PASS/FAIL counts in the summary.

### D5 — Produce `output/testgen/testgen-001.md`
Structure:
```
# MWU-CRUD-001 — TestGen Report
## 1. Test counts (before / after)
## 2. BR-C coverage matrix
## 3. Backend pytest result
## 4. Frontend vitest result
## 5. Deferred items resolved
## 6. Coverage estimate
## 7. Residual items
```

## Constraints

- **No application-code changes** unless Self-Review explicitly deferred a fix to this stage.
- **No new files** beyond test enhancements.
- **Honour the layer firewall** — frontend tests don't import backend code.

Append audit:
```json
{"ts":"<ISO>","event":"stage_complete","stage":"testgen","artefact":"output/testgen/testgen-001.md","backend_tests_total":<N>,"backend_tests_passed":<N>,"frontend_tests_total":<N>,"frontend_tests_passed":<N>,"agent":"general-purpose","model":"claude-sonnet-4-6"}
```

Return ≤ 500-word summary.
